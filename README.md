## Featured Projects

### [Archives Project — Storage & Query Engine in C](https://github.com/lipe-manza/archivesProject)

A low-level storage and query engine built in C, exploring how database internals work without relying on an external DBMS.

- Persistent binary files, fixed-size records and RRN addressing
- B-Tree indexing with insertion, deletion and rebalancing
- Hash tables with separate chaining
- Logical deletion and free-list space reuse
- Nested-loop, index-based and sort-merge joins

**Tech:** `C` `Data Structures` `File I/O` `B-Trees` `Algorithms`

### [Emergency Room Management System](https://github.com/lipe-manza/Hospital_T2_AED1)

A modular emergency room simulation implementing patient management, risk-based triage and persistent storage.

- Five-level priority-based patient scheduling
- AVL trees, priority queues and stacks
- Binary-file persistence
- Patient registration, retrieval and medical history management

**Tech:** `C` `AVL Trees` `Priority Queues` `Binary Files`

### [Graph Algorithms](https://github.com/lipe-manza/graphsProjects)

Implementations and experiments involving graph data structures and algorithms in C.

**Tech:** `C` `Graph Theory` `Algorithms`
